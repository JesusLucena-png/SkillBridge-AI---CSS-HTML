Arquitectura en Docker y Microservicios

Descripción General

Domina la forma en que los desarrolladores y las organizaciones construyen, comparten y ejecutan aplicaciones. Este programa integral está diseñado para proporcionar una base técnica sólida en virtualización ligera, centrándose en el despliegue de arquitecturas de microservicios robustas y escalables.

Objetivos de Aprendizaje

  • Creación y optimización de imágenes Docker con multi-stage builds.
  • Orquestación básica con Docker Compose para entornos locales.
  • Gestión de redes aisladas y seguridad de contenedores.
  • Integración de volúmenes para persistencia de datos.

Prerequisitos

  • Conocimiento básico de Linux y línea de comandos.
  • Experiencia previa en desarrollo de APIs (Java/SpringBoot).
  • Entorno de desarrollo con mínimo 8GB de RAM.
